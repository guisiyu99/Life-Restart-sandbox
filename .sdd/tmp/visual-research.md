## 用户选定方向

- 采用：**B + C 融合**（沉静人生沙盘 + 卡牌翻牌动效）
- 选择原因：
  - **B** 提供双圈 16 主题、8 轮时间轴、三维属性仪表盘的信息架构，契合 18+ 决策练习与历史复盘
  - **C** 在中央事件区强化翻牌/抽卡仪式感，与「方案 C：双圈抽事件 + 翻牌 UI」产品机制一致
  - 融合后兼顾策略可读性与单局沉浸感，且可与 Ant Design 技术栈对齐

## 可复用视觉规则

- **页面结构**：
  - 全局：顶栏（Logo + 导航：首页 / 新游戏 / 历史复盘 + 用户菜单）
  - 对局页：**顶栏属性区**（金钱 / 精力 / 喜悦）+ **左侧 8 轮时间轴** + **中央大卡翻牌区** + **右侧圈/主题选择面板**（按年龄段显隐规则）
  - 回顾页：时间轴摘要 + 结局标签 + AI 总结段落 + 三维终局数值
  - 历史列表：卡片列表，每项为一局人生摘要
- **组件形态**：
  - 生活圈 Tab / 事业圈 Tab；16 子主题宫格（40 前可选）
  - 中央 **大尺寸事件卡牌**（3:4 比例），背面为圈/主题图案，正面为 AI 事件文案
  - 翻牌动画：rotateY 180° + 轻微 scale；揭晓后下方展开 2–3 选项按钮
  - 属性变化：选项确认后浮动 +/- 数字动画
  - 进度：左侧竖向 Stepper / Timeline，当前轮高亮，已完成轮打勾
- **色彩倾向**：
  - 底色：浅米 `#FAF8F5` 或浅灰 `#F5F5F5`
  - 生活圈：珊瑚 / 暖粉 `#FF7875` ~ `#FFA39E`
  - 事业圈：靛蓝 `#597EF7` ~ `#2F54EB`
  - 卡牌：生活圈暖色渐变背、事业圈冷色渐变背；正面白底深字
  - 属性色：金钱金 `#FAAD14`、精力绿 `#52C41A`、喜悦粉 `#EB2F96`
- **字体/字号倾向**：正文 14–16px；事件标题 18–20px 加粗；AI 总结 15px 行高 1.8；辅助 12px 灰色
- **间距/圆角/阴影**：卡牌圆角 12–16px；卡片阴影 `0 8px 24px rgba(0,0,0,0.12)`；宫格间距 8px；时间轴节点 24px
- **信息密度**：对局页中等密度——属性与时间轴常显，事件区留白充足便于阅读 AI 文案

## 原型阶段必须参考

- NeoLife 仪表盘：顶栏多维属性展示与分区导航
- 人生重开模拟器：人生总结页结构与重开 CTA 位置
- Reigns / 卡牌桌游范式：中央大卡 + 左右滑/点击抉择的动效节奏（仅借鉴交互，不复制美术）

## 禁止照搬

- 不复制竞品品牌、Logo、真实文案、商业数据、梗事件内容
- 不复制人生重开模拟器黑底像素风全套 UI（仅借鉴总结页信息层次）
- 只借鉴结构、交互、视觉规律
