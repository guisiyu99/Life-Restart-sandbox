# Bug 修复报告：圈子 Tab 与子主题按钮样式层级不清

## 用户原话

> /sdd-bugfix tab和下面按钮做一个样式区分

（附截图：P05 右侧「生活圈/事业圈」与下方 8 个子主题 chip 外观几乎相同，用户难以区分一级/二级选择）

## 经验回查

- 是否存在相关历史经验：**是**（文字对比度 Bugfix，同模块 P05 picker-panel）
- 相关条目：Bugfix: 对局页主题选择文字看不清
- 为什么仍然犯错：上次只修对比度，未建立控件层级视觉规范；Tab 与 Chip 复用了同一套「描边矩形按钮」样式

## 问题分析

- **现象**：圈子 Tab（生活圈/事业圈）与子主题宫格按钮形状、尺寸、边框风格一致，视觉层级扁平
- **影响范围**：P05 对局页右侧选择面板（40 岁前可选子主题阶段）
- **直接原因**：`.circle-tab` 与 `.theme-chip` 共用相似的 padding、圆角、2px 描边矩形样式
- **根本原因**：实现时未按 ui-design-spec 区分「一级圈子切换」与「二级子主题选择」的控件形态

## 修复方案

- **修改文件**：
  - `frontend/src/pages/GamePlayPage.tsx` — 增加「人生圈子」「子主题」分区标签；子主题包在 `.theme-section` 内
  - `frontend/src/pages/GamePlayPage.css` — Tab 改为 pill 分段控制器；子主题改为更小、细边框 chip；虚线分隔两级区域

- **修改说明**：
  | 层级 | 控件 | 新样式 |
  |------|------|--------|
  | 一级 | 生活圈/事业圈 | 全宽 pill 分段容器 + 渐变填充选中态 + Outfit 粗体 15px |
  | 二级 | 8 个子主题 | 虚线分隔下方、12px 小 chip、1px 浅边框、选中才加硬阴影 |

## 验证方式

- **前端验证**：
  1. 进入对局页（40 岁前轮次）
  2. 确认上方为 pill 分段 Tab，下方有「子主题」标签 + 小 chip 宫格
  3. 两级区域视觉明显不同，切换圈子/主题交互正常

- **终端验证**：`cd frontend && npm run type-check`
